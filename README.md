# Insaurance-new-buisness-forcaster
Cheach the forcast of new buisness for insaurance
How to run

1. pip install -r requirements.txt
2. python -m streamlit run app.py

Keep master_sales_data.csv in the same folder as app.py.

Note: prophet can take a couple of minutes to install the first time
(it pulls in a small C++ compiler toolchain called cmdstan). This is normal,
just let it finish.
