# Insaurance-new-buisness-forcaster
Cheach the forcast of new buisness for insaurance
How to run

1. git clone https://github.com/chayanpaul-rgb/Insaurance-new-buisness-forcaster.git
2. cd Insaurance-new-buisness-forcaster
3. python -m venv venv
4. venv\Scripts\Activate.ps1
5. pip install -r Requirements.txt
6. python -m streamlit run app.py
7. pip install -r requirements.txt

Keep master_sales_data.csv in the same folder as app.py.(To run in Vs code)

Note: prophet can take a couple of minutes to install the first time
(it pulls in a small C++ compiler toolchain called cmdstan). This is normal,
just let it finish.
